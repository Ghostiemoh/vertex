Decision Rules — When You're Stuck

Defaults · No exceptions without reason
  1. Reliability > features. Every time.
  2. One user > ten signups. Talk to settlers.
  3. Volume > vanity. $100 settled beats 10K followers.
  4. Ship daily > ship perfectly. Velocity is the moat.
  5. Build in public > build in private. Even embarrassing.
